# 1 iam permission for ec2
* name in this format `KarpenterNodeRole-${CLUSTER_NAME}`
* trust policy `sts:AssumeRole` `ec2.amazonaws.com`
* `AmazonEKSWorkerNodePolicy`
* `AmazonEKS_CNI_Policy`
* `AmazonEC2ContainerRegistryReadOnly`
* `AmazonSSMManagedInstanceCore`

# 2 iam for karpenter SA
* `KarpenterControllerRole-${CLUSTER_NAME}`
* iam role with WebIdenity trust policy for all SA
* or change the `iam passrole`

# 3 add to aws-auth
* edit aws-auth or add NodeRole to it
```yaml
    - groups:
      - system:bootstrappers
      - system:nodes
      rolearn: <ROLE of the ec2>
      username: system:node:{{EC2PrivateDNSName}}
```
OR
```bash
eksctl create iamidentitymapping \
  --username system:node:{{EC2PrivateDNSName}} \
  --cluster "mycluster" \
  --arn "<KarpenterNodeRoleARN>" \
  --group system:bootstrappers \
  --group system:node
```
